## Introduction

Wireless Reap3r is \*currently a wardriving tool that is based off of [Wardriver.uk](https://wardriver.uk/start) by Joseph Hewitt and [Signal Sleuth](https://463n7.io/products/slim-signal-sleuth-kit) by 463n7. Wardriver.uk only 2 ESP32Us and can only scan 2.4GHz WiFi APs, and Signal Sleuth uses BW16 for 5GHz scanning while Wireless Reap3r with similar architecture, uses ESP32C5 as 5GHz scanner, ESP32U as 2.4GHz scanner, and ESP32S3 as the main processor for the other two ESP32s.

This project is mainly created with mind of using it as our main Wardriving Tool for recently concluded ROOTCON 20 Security Conference for WiFinders event competition. Thanks to my teammates from [Shinigami.ph](https://shinigami.ph/) and this device, we won this year's iteration of ROOTCON 20 WiFinders.

However, this project will further improve the hardware and firmware to do other wireless functionalities. We're aiming this time for hardware and software to be usable for wireless penetration testing and not just for wardriving.
